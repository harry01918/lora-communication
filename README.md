# LoRa Communication

## Overview

This project demonstrates wireless communication between a LoRa
transmitter and receiver using a microcontroller.

The transmitter sends data wirelessly through the LoRa module, and the
receiver receives and displays the transmitted data.

## Objective

- Understand LoRa wireless communication
- Configure LoRa transmitter and receiver
- Send data wirelessly
- Receive and verify the transmitted data

## Technologies Used

- Embedded C/C++
- Arduino IDE
- Microcontroller
- LoRa Module
- SPI Communication
